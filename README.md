# Pixi

**Turn any photo into pixel art, right in your browser.**

🔗 **Live demo:** https://apoben.github.io/Pixi/

## Features
- Adjustable resolution, palette size and detail level
- **k-means color quantization** for a clean, limited palette
- Sharpening pass for crisper edges
- One-click PNG download
- Runs fully client-side — images never leave your device; installable as a PWA

## Tech Stack
Vanilla JavaScript · Canvas API · Service Worker

## Run Locally
```bash
npx serve .
```
